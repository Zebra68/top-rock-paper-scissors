# top-rock-paper-scissors
TOP Foundation Javascript project. Rock Paper Scissors console game

# pseudocode
COMPUTE Computer random choice
    GET Random assignment from Rock, Paper or Scissor
OBTAIN Player choice
    GET input from prompt
        COMPUTE input to assignment of Rock, Paper or Scissor
CALCULATE outcome
    IF Paper vs Rock THEN Paper wins
    IF Rock vs Scissor THEN Rock wins
    IF Scissor vs Paper THEN Scissor wins
    IF answers are equal THEN Tie
INCREMENT score for winner
    IF Tie, increment by 0 for both
REPEAT from start
